Overview
Developed a stock price prediction model using Double Exponential Smoothing, improving forecast accuracy with an 80% reduction in computation time through parallelized hyperparameter tuning. The model achieved a 46% reduction in RMSE and a 34% improvement in MAPE. Designed data preprocessing pipelines for a 6-year historical dataset, ensuring strong model generalization and outperformance of baseline models. Created visualizations and dashboards for stakeholders, facilitating data-driven decision-making with clear insights into stock price trends and model performance.

●	Built a stock price prediction model in Python using Double Exponential Smoothing, optimizing hyperparameters to cut Root Mean Square Error (RMSE) by 46% (4.33 to 2.17) and improve Mean Absolute Percentage Error (MAPE) by 34%
●	Developed a 6-year historical stock data pipeline generating 12 forecasts with a mean RMSE of 2.30 and MAPE of 1.53
●	Visualized forecast performance through time-series plots and Tableau dashboards with calculated measures providing insights into forecast precision, trends, and potential investment risks, enabling investors to make informed decisions
